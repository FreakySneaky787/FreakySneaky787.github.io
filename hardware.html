Hardware

Simple OS doesn't promise to run on every computer. These are the computers it is known to work on – tested by us or reported by people who use it – and what didn't work.

Lenovo ThinkPad E16 Gen 3 (21TF: Intel Core 5 210H, Intel graphics, Intel Wi-Fi) is in daily use. Wi-Fi: with one router, the 5 GHz connection on a wide 160 MHz channel was slow. Setting the network to 2.4 GHz in Control Center → Wi-Fi fixed it. Sound includes Bluetooth headphones. Suspend and waking up were checked with 1.0.7.

Lenovo ThinkBook has run Simple OS since 1.0. Bluetooth keyboards and phones pair, and a monitor plugged in later turns on by itself. The power button has to be held for about a second; the firmware ignores a quick tap.

Dell OptiPlex 9020 (desktop): with 1.0.3, the installer could leave the disk unable to start (#62, #64). This was fixed in 1.0.4 and tested in a virtual machine set up like this computer (legacy BIOS, MBR, “Install alongside” in an extended partition). A test on the real computer is still to come.

Virtual machines

Releases are tested in QEMU/KVM before they are published: installing with legacy BIOS, with UEFI, and with UEFI and Secure Boot on (Microsoft keys), and updating from the previous version. In virt-manager (SPICE) the screen size follows the window, and copy and paste works between the virtual machine and your computer.

Not tested yet – help wanted

  • A desktop with an NVIDIA graphics card and the NVIDIA driver
  • A laptop with AMD graphics
  • Dual boot with Windows on a real computer
  • Secure Boot on with an installed system on a real computer
  • Older Mac laptops (Intel). They usually need the Broadcom Wi-Fi driver.

Known limitations

  • 64-bit PCs only (x86-64). There's no version for ARM computers (Raspberry Pi, Apple Silicon Macs) or 32-bit PCs.
  • The NVIDIA driver only works with Secure Boot off. The driver is built on your computer, and the firmware doesn't know its signature. Turn Secure Boot off in the firmware settings, then install the driver in Control Center → System & Updates → Hardware & Drivers.
  • GeForce RTX 50 cards: the NVIDIA driver in Debian 12 doesn't support them yet, so Hardware & Drivers doesn't offer it. The picture works with the free driver, without 3D acceleration.
  • Broadcom Wi-Fi (many older laptops and Macs) needs an extra driver from Hardware & Drivers. That needs an internet connection by cable or through a phone (USB tethering) first.
  • One display scale for all screens. Simple OS uses X11, which has no separate scale per monitor. With a 4K laptop screen and a normal external monitor, the main screen decides.
  • Lenovo laptops may show “Self-Healing BIOS ESP” once on the first start after installing. That's harmless and doesn't come back.

Report your computer

  1. Open a hardware report on GitHub. It asks for the same columns as the table above.
  2. In Simple OS, Menu → Help → Report a Problem creates a text file on your desktop with the hardware details (model, graphics, Wi-Fi chip, sound). Please attach it.

Your computer then gets a row here, and anything that didn't work becomes an issue of its own.
