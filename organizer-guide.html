Your first run

  1. Start Simple Organizer. The first time, it picks your Downloads folder. After that it remembers the last folder you used.
  2. To choose another folder, click Browse… in the top bar.
  3. Click Scan (Ctrl + R). Nothing is moved yet. The Preview tab lists every file that would be moved and where it would go.
  4. Look through the list. Right-click a row to open the source or target folder, or to copy a path.
  5. Click Organize (Ctrl + O). You'll see how many files will be moved and how big they are. Confirm, and the files are moved into category folders inside the folder you scanned.

To reverse it, click Undo last (Ctrl + Z).

Only one task runs at a time; the other buttons are disabled while a scan or move is running. If you close the window during a task, the program waits until it's finished. Keyboard shortcuts also work with Caps Lock on, but not while a task is running or a dialog is open.

About .ts files

A .ts file can be TypeScript code or a video. Simple Organizer looks inside the file to tell them apart: videos go to Videos/TS, code goes to Code/JavaScript. For OneDrive files that are only stored online, the file isn't opened (that would download it). There, a .ts file of 1 MB or more counts as a video.

Files that are never moved

  • System files like desktop.ini, Thumbs.db and .DS_Store
  • Shortcuts: .lnk, .url, .desktop, .webloc
  • Downloads that are still running, temporary files and Office lock files
  • Simple Organizer itself, so you can keep the program in your Downloads folder
  • Hidden files, unless you turn on Include hidden files

Rules

Rules send files to a folder you choose, before the normal sorting by file type. They're checked from top to bottom, and the first rule that matches wins.

Create a rule

Open the Rules tab and click Add rule. Every rule has a name, a condition, a value, a target folder, and can be switched on or off.

ConditionMatchesExample value
extensionFiles with this extension (also works for tar.gz)pdf
name_patternFile names matching a pattern, upper/lower case doesn't matterinvoice_*.pdf
min_size_mbFiles at least this big (in MB)100
max_size_mbFiles at most this big (in MB)10
older_than_daysFiles not changed for at least this many days365
newer_than_daysFiles changed in the last … days7

Target folder

The target folder is always inside the folder you scan. Sub-folders like Work/Reports are fine. Not allowed: full paths, drive letters, .., the characters < > : " | ? *, Windows names like CON or NUL, and names that end with a dot or space. A rule with an invalid target is skipped, and a warning is written to the log.

Manage rules

  • Click the dot in the first column (or press Space) to switch a rule on or off.
  • Double-click a rule or use Edit to change it.
  • Use ↑ and ↓ to change the order. Remember: the first match wins.
  • Rules don't use sub-categories. The target folder is used exactly as you typed it.

Rules are saved in rules.json. If another program (for example a sync tool) blocks that file, the scan stops with a message instead of sorting without your rules.

Why wasn't a file moved?

After a scan, the Log tab shows how many files were skipped. The usual reasons:

  • It's a system file, shortcut, temporary file or a download that's still running.
  • It's hidden and Include hidden files is off.
  • It's in a sub-folder and Scan subdirectories is off.
  • It's inside a Git project, a link or a junction, or already in a category folder.
  • A file with the same name as the category folder is in the way.
  • A scan limit (depth, number of folders, time) was reached.
  • It's already in the right place.

A file went into the wrong folder? Add a rule. Rules are checked before the normal sorting.

Messages

MessageWhat it means
“… is an unusual folder” / “Scan this folder anyway?”You're about to scan a whole drive, your home folder, a system folder or a Git project. Only confirm if you really mean it. Your answer is remembered.
“Auto-organize paused”The folder wasn't found (for example an unplugged drive), or it's an unusual folder you haven't confirmed.
“Simple Organizer is already running.”Only one copy can run. Switch to the window that's already open.
“rules.json could not be read” / “Rules not available”Another program (sync tool, antivirus) is blocking the file. Try again in a moment.
“… online-only … not staged”OneDrive files that are only online aren't staged, because that would download them. Organize without staging mode.
“Something went wrong”An unexpected error. Details are in error.log. Please report it and attach the file.

Windows

  • Duplicates on a network drive can't go to the Recycle Bin, because network drives don't have one. They're left where they are instead of being deleted.

Linux

  • Dialogs have square corners. Rounded corners need window transparency, which only works on Windows.
  • Drag and drop doesn't work: install tkinterdnd2 with pip.
