What it does

Simple Organizer sorts the files in one folder into sub-folders by type. It's made for folders that fill up over time, like Downloads or the Desktop.

It doesn't need an internet connection, doesn't run in the background and doesn't delete anything. Files are only moved, and every run can be undone.

On Windows it's a single program you start from a ZIP file, without installing. On Linux it runs with Python. macOS is not supported.

How to use it

  1. Choose a folder, for example Downloads.
  2. Click Scan (Ctrl + R). Nothing is moved yet. The Preview tab shows where each file would go.
  3. If it looks right, click Organize (Ctrl + O) and confirm.
  4. Changed your mind? Undo last (Ctrl + Z) puts everything back.

Categories

Files are sorted into these folders:

  • Images
  • Documents
  • Archives
  • Videos
  • Music
  • Code
  • Programs
  • Disk Images
  • Others

If you want, files can also go into sub-folders such as Images/Photos or Documents/PDFs. You can add your own rules on top (see below).

The user guide lists every file extension and sub-folder.

Features

FeatureWhat it does
PreviewA scan only plans the moves. You see the result before anything happens, can search and sort it, keep single files where they are with Don't move, and export it as a CSV file.
UndoUndo the last run, or any of the last 20 manual and 20 automatic runs, in any order. The history shows which folder each run belongs to.
RulesYour own sorting rules by file extension, name pattern, size or age, also combined. For example: everything with “invoice” in the name goes to Invoices, or PDFs older than a year go to Archive. How rules work
Staging modeCollect moves first, then commit or revert them together.
Auto-organizeSorts the folder on a schedule while the program is open.
Duplicate finderFinds files that are exactly the same. Copies go to the Recycle Bin or Trash only if you confirm.
Sub-folder scansCan scan inside sub-folders, with limits for depth, number of folders and time.
LookLight and dark theme. Your settings are saved.

What it won't touch

  • Files are never deleted or overwritten. If a file with the same name already exists, the new one gets a number, like photo_1.jpg.
  • System files, shortcuts, temporary files and downloads that are still running are skipped.
  • OneDrive files that are only stored online are not downloaded.
  • For whole drives, your home folder, system folders and Git projects, it asks before doing anything.
  • The undo history is written while files are being moved. If the program crashes, you can still undo.
  • Only one copy of the program and one task can run at a time.

Installation

Windows 10 and 11

  1. Download simple_organizer_windows_v3.5.0.zip.
  2. Extract the ZIP file.
  3. Start simple_organizer.exe.

The program isn't code-signed yet, so Windows SmartScreen may show a warning. Right-click the file, open Properties and tick Unblock.

Linux

You need Python 3.11 or newer with Tkinter. There is no ready-made Linux package yet.

# Debian / Ubuntu
sudo apt install python3-tk

# Fedora / Bazzite
sudo dnf install python3-tkinter

git clone https://github.com/FreakySneaky787/Simple-Organizer.git
cd Simple-Organizer
python3 main.py

Settings and logs

If something goes wrong, the program writes an error.log. Please attach it when you report a problem.

SystemFolder
Windows%APPDATA%\simple_organizer\
Linux~/.config/simple_organizer/ and ~/.local/share/simple_organizer/
