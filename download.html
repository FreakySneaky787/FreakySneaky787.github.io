Check the download

The checksum makes sure the file wasn't damaged while downloading. Compare the result with the SHA-256 value above.

On Windows, open PowerShell in your Downloads folder and run:

Get-FileHash .\Simple-OS.iso -Algorithm SHA256

On Linux, put the ISO and the .sha256 file in the same folder and run:

sha256sum -c Simple-OS.iso.sha256

If the values don't match, download the ISO again.

Which one do I need?

Simple OS replaces the operating system on a computer, for example Windows. You install it from a USB stick.

Simple Organizer is a normal program that runs on Windows or Linux and tidies up your folders.
