Simple-Project

A small open-source project from Switzerland. I write software for people who want their computer to just work. So far there are two programs: an operating system and a file organizer.

Both are free. The code is on GitHub.

Simple OS1.0.5

A Linux distribution based on Debian 12. It sets itself up on the first login and installs updates by itself.

DownloadLearn more

Simple Organizer3.5.1

Sorts a messy folder like Downloads into sub-folders. Only moves files, never deletes them, and every run can be undone.

Oct172026

Simple OSSimple OS 1.0.5

A bug-fix update with a few new features and a new ISO. The right-click menu is sorted into Apps, Settings, Tools and Help, and the Control Center has smaller, clearer pages. You can choose your default apps, switch off apps that start by themselves, see the battery level of Bluetooth headphones and open a calendar by clicking the clock. Simple OS installed next to Windows keeps the clock the way Windows does, and a “What's new” window shows what changed after each update.

Oct162026

OrganizerSimple Organizer 3.5.1

A bug-fix update. “Don't move” is now remembered after a restart, so automatic runs leave those files alone too. A duplicate only goes to the Recycle Bin if the copy you keep still has the same content, and the history can no longer end up empty after a power cut. Files named like a category folder, folders named like a category and the folders of your own rules are now handled correctly.

Release notes
Oct142026

Simple OSSimple OS 1.0.4

A bug-fix update with a new ISO. The screen locks when you leave, the power button asks first, and there's a brightness slider. Installing is safer: the installer can't run twice, the computer doesn't switch off while it works, and it reminds you to remove the USB stick. Installations in German and other languages now really get their language, the keyring works from the first login, older PCs can install next to another system, and Windows or other systems stay in the boot menu after updates.

Release notes
Oct132026

OrganizerSimple Organizer 3.5.0

The first feature release since the reviews. You can keep single files where they are with “Don't move”, search, sort and export the preview as a CSV file, and give a rule several conditions, like “PDF and older than a year”. The history now shows which folder each run belongs to, and the program starts about twice as fast.

Release notes
Oct122026

OrganizerSimple Organizer 3.4.5

Bug-fix release with 13 fixes from the fourth code review. A rules file saved in the wrong text encoding no longer stops the program from starting, read-only files can be moved to another drive, and the Trash only removes a duplicate if the copy you keep still exists. LibreOffice lock files and running Firefox downloads are left alone.

Simple OSSimple OS 1.0.3

A maintenance update for every 1.0 install. It arrives through Software Updates (about 60 MB), so there's no need to reinstall. Night light now works on real hardware, the Control Center has new pages for Mouse & Touchpad and Date & Time, and monitors, projectors and TVs turn on by themselves when you plug them in.

OrganizerSimple Organizer 3.4.4

Bug-fix release with 23 fixes from the third code review. Moving files between two drives no longer leaves copies behind, shortcuts on the Desktop are never moved, and there are two new categories: Programs and Disk Images.
