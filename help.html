Simple OS

Can I try it without installing it?

Yes. Start your computer from the USB stick and Simple OS runs as a live system. Nothing on your computer changes until you start the installer.

How do I get updates?

You don't have to do anything. Simple OS checks for updates after you log in, every 12 hours and after sleep, and installs them with the Software Updates app. New Simple OS versions come the same way.

Will a new version reset my settings?

No. Settings you've changed yourself are kept when a new version is installed.

How long will Simple OS get security updates?

Simple OS 1.x is based on Debian 12, which gets security updates until June 2028. Simple OS 2.0, based on Debian 13, is planned.

Which programs can I install?

Everything in the Software Store, which uses Flathub. That includes browsers, office apps, games, image editors and much more.

Can I play games?

Yes. The Setup Wizard has a gaming option, and Steam works, also on older NVIDIA cards.

I can't host a LAN game or use Steam Remote Play as host.

The firewall blocks that. Turn the firewall off in Control Center → System → Security while you play, and turn it back on afterwards.

Is Simple OS available in my language?

Partly. Firefox, LibreOffice and the dictionaries use the language you pick in the installer. The Simple OS tools themselves (Setup Wizard, Control Center and so on) are only in English for now. Translations are planned for version 1.1.

How do I change the keyboard layout?

In Control Center → System. You can change it at any time.

Where can I see all keyboard shortcuts?

Press Super + H (the Super key is the one with the Windows logo). A few useful ones are also listed on the Simple OS page.

Simple OS: hardware

Does it work with NVIDIA graphics cards?

Yes, but the NVIDIA driver currently only works with Secure Boot turned off. Turn off Secure Boot in the firmware settings (BIOS/UEFI), then install the driver in Control Center → System → Hardware & Drivers.

My Lenovo laptop showed a “Self-Healing BIOS ESP” message.

That's normal and harmless. It can appear once on the first start after installing, because the Lenovo firmware adjusts its backup to the new disk layout. It won't come back.

I don't see the battery charge limit option.

It only appears on laptops that support a charge limit. Most Lenovo, ASUS, Dell, HP and Framework laptops do.

BIOS or firmware updates don't install.

They're only installed while the laptop is plugged in. Whether your model gets them at all depends on the manufacturer (through LVFS).

My Wi-Fi keeps dropping.

Some routers have unstable 5 GHz channels. In Control Center → Wi-Fi you can set a network to use 2.4 GHz only.

How do I use a second monitor or a projector?

Plug it in; it turns on and extends the desktop by itself. Press Super + P to switch the display mode.

Simple Organizer

Can it delete my files?

No. It only moves files and never overwrites them. Every run can be undone. The duplicate finder only moves copies to the Recycle Bin if you confirm it.

I organized a folder by mistake. How do I get my files back?

Click Undo last (Ctrl + Z), or choose the run under History….

Windows warns me when I start it. Is that normal?

Yes. The program isn't code-signed yet, so Windows SmartScreen doesn't know it. Right-click the file, open Properties and tick Unblock, or click “More info” and then “Run anyway”. The source code is public on GitHub.

Can I keep the program in my Downloads folder and organize Downloads?

Yes. Simple Organizer never moves itself.

Why wasn't a file moved?

Check the Log tab after a scan. Common reasons are hidden files, files in sub-folders, files that are still downloading and shortcuts. The user guide has the full list.

A file went into the wrong folder.

Add a rule. Rules are checked before the normal sorting by file type.

What happens if two files have the same name?

Nothing is overwritten. The file that is moved gets a number at the end, for example photo_1.jpg.

Does it need the internet or run in the background?

No. It works completely offline. Auto-organize only runs while the window is open.

Does it work on a Mac?

No, only Windows 10, Windows 11 and Linux.

General

Does it cost anything?

No. Both programs are free and open source. Simple OS uses the GPL-3.0 license, Simple Organizer the MIT License.

Who makes this?

Simple-Project is made by FreakySneaky from Switzerland. More on the About page.

Can I help?

Yes, and you don't need to program. See Get involved.

Report a problem

Problems are collected on GitHub. You need a free GitHub account to open an issue.

Simple OS

  1. If you can, use Report a problem in Simple OS. It's in the menu.
  2. Or open an issue on github.com/FreakySneaky787/Simple-OS/issues.
  3. Write what you did, what happened, and which computer you have (model, graphics card).

Simple Organizer

  1. Open an issue on github.com/FreakySneaky787/Simple-Organizer/issues.
  2. Write what you did and what happened, and which version you use.
  3. Attach error.log if there is one. On Windows it's in %APPDATA%\simple_organizer\, on Linux in ~/.config/simple_organizer/.
