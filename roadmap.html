Simple OS 1.0.6Released

Bug-fix release with a new ISO · released 24 October 2026 · Release notes

  • Control Center → Wi-Fi lists the networks again, online and offline (#76)
  • Closing the Software Center during an installation no longer stops it halfway (#83)
  • Choose the app for documents, spreadsheets and presentations (#75)
  • Refresh rates: no more three times “60 Hz” (#78)
  • Search finds dates like 2026-10-20 instead of calculating them (#82)
  • Installing next to Windows without internet: the clock stays right (#73)
  • “What's new” also for older accounts (#79), text fixes (#80), release tools (#71, #72, #77)
  • Signing in again after the screen locked itself: no more black screen (#88)

Simple OS 1.0.5Released

Bug-fix release with a new ISO · released 17 October 2026 · Release notes

Tested on a Lenovo ThinkPad E16 and in virtual machines, including an installation next to Windows.

  • Clearer menus: the right-click menu has Apps, Settings, Tools and Help, and the Control Center has smaller pages
  • A “Default apps” page: browser, mail, PDF and more (#38)
  • Startup apps: switch off programs that start at login, or add one (#39)
  • Battery level of Bluetooth headphones (#37)
  • A calendar when you click the clock (#45)
  • Next to Windows: the clock stays right, and a note about Windows “fast startup” (#46)
  • A “What's new” window after updates (#65)
  • Signing out and in again keeps the power button, night light and update messages working
  • Search with a Swiss, German or French keyboard: Y and Z are no longer swapped

Simple OS 1.0.4Released

Bug-fix release with a new ISO · released 14 October 2026 · Release notes

Tested on a Lenovo ThinkBook, and in virtual machines set up like an older BIOS PC (Dell OptiPlex 9020) and a UEFI laptop with Secure Boot.

  • The screen locks when you leave, and videos keep it on (#25)
  • The power button opens the power menu instead of shutting down at once (on some laptops: hold it for about a second)
  • Brightness slider in Control Center → Display
  • Wi-Fi country set automatically from the time zone
  • git included
  • Installer: runs only once, no switching off while it works, “remove the USB stick” before the restart (#62, #64)
  • Setup Wizard skips the internet step when you're online (#63)
  • Installations in other languages get their language and language packs (#31)
  • No “new keyring” prompt after the first login (#32)
  • Install next to another system on older BIOS PCs; other systems stay in the boot menu after updates
  • Confirmed on real hardware: night light, microphone, external monitors, Mouse & Touchpad, Date & Time, Bluetooth pairing with a keyboard and phone

Simple OS 1.1Planned

Feature release · about 2–3 months after 1.0

  • Display scaling for high-resolution screens: a Scale setting from 100 to 200% in Control Center → Display
  • Language & Region page, and translations of the Simple OS tools
  • A small app to test the webcam
  • A Users & accounts page: add and remove users, change passwords and pictures, automatic login (#68)
  • Faster start and smaller system: smaller initramfs, AppArmor profiles, zstd compression (#19)
  • Tests on more hardware: NVIDIA desktop, AMD laptop, dual boot with Windows, Secure Boot

Simple OS 2.0 on Debian 13Planned

Simple OS 1.x is based on Debian 12 “Bookworm”. Debian 12 gets security updates through Debian LTS until June 2028, so 1.x stays safe to use while 2.0 is prepared.

Simple OS 2.0 will be based on Debian 13 “Trixie”. That brings a newer kernel, newer graphics drivers (Mesa) and newer firmware. A lot of things have to be checked again for this: NVIDIA drivers, the installer, night light, Secure Boot and the Simple OS tools.

StepWhen

Simple OS 2.0When the upgrade has been tested on several real computers

What happens to existing installs? Not decided yet. The preferred way is a guided upgrade tool that creates a restore point first. The alternative is a fresh install that takes your home folder along.

Simple Organizer

The current version is 3.5.2 (19 October 2026), the second bug-fix update for 3.5.0. 3.5.0 added “Don't move”, search, sorting and CSV export in the preview and rules with several conditions. 3.5.1 and 3.5.2 fix the 15 issues found afterwards. The tests run automatically on GitHub.

No dates yet. These are the next things on the list:

  • Watch mode that sorts new files as soon as they appear
  • Flatpak or AppImage package for Linux
  • Code-signed Windows version, so SmartScreen doesn't warn anymore
  • Run the automated tests on Linux too
