About

Who I am

Hi, I'm FreakySneaky from Switzerland. Simple-Project is where I publish the software I make.

A lot of software is more complicated than it needs to be. With Simple-Project I try to build things that work without a manual: an operating system that sets itself up, and a tool that cleans up your folders without putting your files at risk.

Everything is free and open source. Anyone can read the code, check what it does, or help.

How releases are made

Simple OS is built with Debian's live-build tools. Before a release, the image is started and installed in virtual machines in three modes: BIOS, UEFI and UEFI with Secure Boot. Things that can only be checked on real hardware are tracked as “Verify …” issues on GitHub.

Updates are published to a signed package repository. That's how installed systems get new versions without reinstalling.

Work is normally pushed to GitHub together with a release, and every release has a tag (for example v1.0.3) that matches exactly what was published. More about this under How the project works.

Simple Organizer goes through regular code reviews. Version 3.4.5, for example, fixed 13 issues found in the fourth review, and since 3.5.0 every release is checked by automated tests.

Privacy

This website doesn't use cookies, tracking or analytics, and it has no forms. I don't collect any personal data.

The site is hosted on GitHub Pages, and downloads come from GitHub. When you visit, GitHub processes technical data such as your IP address to deliver the pages and keep the service secure. Details are in the GitHub Privacy Statement.

Simple Organizer works completely offline and sends no data. Simple OS only connects to its package servers and Debian's to check for and download updates, like any Linux system.
