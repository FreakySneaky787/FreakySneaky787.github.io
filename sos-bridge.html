SOS Bridge apps

SOS Bridge runs Windows programs on Simple OS 1.2: double-click a .exe or .msi file. These are the programs it is known to work with – tested by us or reported by people who use it – and the ones that don't.

On this page

SOS Bridge is the free app Bottles with Wine, set up so you don't have to know either: double-click a downloaded .exe or .msi file (or right-click → “Run with SOS Bridge”), and the program installs and opens. Wine doesn't run every Windows program. Your program isn't listed? It may still work – try it, then tell us how it went. Last updated: 26 November 2026 (Simple OS 1.2).

All programs that work also started again after restarting the computer, and their entries appear in the Simple OS menu like any other app. Their Open and Save windows show your own Documents, Downloads, Pictures, Music, Videos and Desktop.

How we test

Each program is tested in a fresh Simple OS 1.2 installation with SOS Bridge (Bottles 67.7 from Flathub, runner soda-11.0-10), set up by SOS Bridge itself on the first double-click:

  1. Open the downloaded installer with a double-click and install it, as a normal user would.
  2. Start it from the Simple OS menu and check one real job: save a file, open a document, connect to a server …
  3. Restart the computer and start it again.
  4. Uninstall it with its own uninstaller – the menu entry has to disappear too.

The test run is documented in issue #153 (24 November 2026).

What never works

  • Programs made for Windows itself: Windows installation media and setup tools, drivers, antivirus and system tuners. They need a real Windows.
  • Microsoft 365 (Word, Excel, Outlook as apps) and current Adobe apps (Photoshop, Premiere, Acrobat Pro). Microsoft 365 works in the browser, and LibreOffice or ONLYOFFICE open Word and Excel files.
  • Games with kernel anti-cheat (for example Valorant, Fortnite and many competitive online games). Many other games run through Steam: in Steam → Settings → Compatibility, turn on “Steam Play for all other titles”.

Good to know

  • The first double-click sets SOS Bridge up once, which takes about a minute. After that, programs open straight away.
  • Windows setup windows (.msi) sometimes show placeholder text (“Lorem ipsum”) on the “Custom Setup” page. That comes from Wine and is harmless.
  • Links in Windows programs open in your normal Simple OS browser.
  • Menu → Help → Windows Programs on Simple OS explains the same in your language, with alternatives.

Report a program

Tried a Windows program with SOS Bridge? Open an issue on GitHub with the program's name and version, where you downloaded it, and what worked: installing, starting, its main job, starting again after a restart, uninstalling. If something didn't work, the exact error message helps a lot. The program then gets a row here.
