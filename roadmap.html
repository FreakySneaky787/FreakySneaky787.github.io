Simple OS 1.1.1Next

Bug-fix release after 1.1

  • Menus that close again after a slow click: the desktop and window menus, the volume slider and the network and sound menus in the taskbar (#104)
  • Software Center, Software Store and GNOME Software each get their own icon, so they can be told apart (#117)

Simple OS 1.2Planned

Feature release after 1.1 · the last feature release of 1.x – after it, 1.2.x gets only fixes and the work goes into Simple OS 2.0 on Debian 13

  • Translations of the Simple OS tools (#43)
  • A Users & accounts page: add and remove users, change passwords and pictures, automatic login (#68)
  • AppArmor profiles (#48)
  • Windows programs: open .exe and .msi files with Bottles, an honest help page about what works, and SOS Bridge, an optional component in the Setup Wizard – off by default, and you can install it later from the Software Store (#85)
  • Tests on more hardware: NVIDIA desktop, AMD laptop, dual boot with Windows, Secure Boot (#49) – report your computer

Simple OS 2.0 on Debian 13Planned

Simple OS 1.x is based on Debian 12 “Bookworm”. Debian 12 gets security updates through Debian LTS until June 2028, so 1.x stays safe to use while 2.0 is prepared.

Simple OS 2.0 will be based on Debian 13 “Trixie”. That brings a newer kernel, newer graphics drivers (Mesa) and newer firmware. A lot of things have to be checked again for this: NVIDIA drivers, the installer, night light, Secure Boot and the Simple OS tools.

Simple OS 2.0When the upgrade has been tested on several real computers

What happens to existing installs? A guided “Upgrade to Simple OS 2.0” tool that creates a restore point first (#52). A fresh install that takes your home folder along stays as the fallback.

2.0 brings only the new base and everything 1.x has by then. New features start with 2.1. New in 2.0 itself:

  • The “Rigi” look: peach as the default color, a new wallpaper for day and night, new logo colors
  • The lifebuoy from the logo as the one loading animation – at startup, in the installer, in the Simple OS tools and while a program starts (#113)
  • A simpler partitioning page in the installer (#101)
  • The upgrade tool (#52), and 1.x computers are never offered 2.0 as a normal update (#106)

Simple OS 2.1 to 2.3Planned

Feature releases after 2.0, one theme each, every two to three months · the order may change with what you report

2.1 – Keep your data safe

  • Backups of your personal files, not only the system (#89)
  • A recovery assistant in the boot menu that brings back a restore point when the desktop no longer starts (#108)
  • Choose when updates are installed: when you shut down or at a set time (#109), and optional automatic security updates (#54)
  • The clipboard history (Super+V) also keeps pictures, and you can pin entries (#110)
  • The split view of the file manager becomes easy to find

2.2 – Usable for everyone

  • Accessibility: screen reader, large cursor, high-contrast theme (#56)
  • Fingerprint reader support with a setup page (#55)
  • A Wayland session to try out, next to the normal one (#87)

2.3 – Tools

  • Wayland becomes the default; the old session stays as a fallback for a while (#87)
  • A screenshot editor: arrows, text, cropping and blurring private details (#111)
  • Optional: RGB lighting and game controllers (#112)

Hardware support is not a release of its own: it grows with every update. Report your computer to help.

IdeasNot scheduled

  • Help screenshots for printers and scanners
  • Sending a problem report to GitHub with one click, privacy first
  • Automatic test builds on every change
  • A version for ARM computers (low priority)
